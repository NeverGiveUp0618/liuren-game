九宗门详解
元首课
有克 · 唯一上克下
›
判断：四课中只有一处「上神克下神」，没有下克上
取法：那个克处的上神就是初传；中传=初传落地盘上的天盘；末传同理
象意：上克下如君令臣，顺正之象，事多顺遂
记：唯一一个上神胜出，当仁不让发用
📐 推导步骤
第①步：逐格检查四课（四格），看每格上神与下神的五行是否相克（木克土、土克水、水克火、火克金、金克木）
第②步：找到唯一一处「上神五行 → 克 → 下神五行」，确认其余三格均无下克上
第③步：取该格的上神直接作初传
第④步：中传 = 查初传在地盘的位置 → 看该位置天盘是什么地支；末传同理再推一步
💡 举例：四课第一格「午（上）/ 子（下）」，午火克子水 = 上克下，且其他格无克 → 元首课，初传 = 午
重审课
有克 · 唯一下克上
›
判断：四课中只有一处「下神克上神」，没有上克下
取法：那个克处的下神为初传；若下神是天干（日干），取日干寄宫地支
象意：臣克君，需重新审视，事多反复、情况复杂
记：下神爬上来发用，事情有点反常
📐 推导步骤
第①步：逐格检查四课，找到「下神五行 → 克 → 上神五行」的格（即下克上）
第②步：确认全部四课中没有任何「上克下」（有则须用涉害法）
第③步：取该格的下神为初传；若下神是天干（日干本身），则取日干的寄宫地支代替
第④步：中末传照常从地盘天盘顺推
💡 举例：第三课「丁（上·火）/ 亥（下·水）」，亥水克丁火 = 下克上，且无上克下 → 重审课，初传 = 亥
知一课
有克 · 多处同类克
›
判断：四课中有多处「上克下」（无下克上），或多处「下克上」（无上克下）
取法（上克下多处）：阳日取第一课上神（干上），阴日取第三课上神（支上）
取法（下克上多处）：阳日取第一课下神，阴日取第三课下神
阳日：甲丙戊庚壬；阴日：乙丁己辛癸
记：多中取一，阳干跟着日干走，阴日跟着日支走
📐 推导步骤（比用法）
第①步：确认四课有多处克，且方向相同（全是上克下，或全是下克上）
第②步：判断日干阴阳：甲丙戊庚壬 = 阳日；乙丁己辛癸 = 阴日
第③步：阳日 → 多个候选中取属阳的地支（子寅辰午申戌）；阴日 → 取属阴的地支（丑卯巳未酉亥）
第④步：筛选后若仅剩一个 → 即为初传；若仍有多个同阴同阳，进入涉害法
💡 举例：壬日（阳），两处上克下，候选上神为「午（阳·火）」和「卯（阴·木）」→ 壬日取阳地支 → 初传 = 午（卯阴被淘汰）
涉害课
有克 · 上下混合克
›
判断：四课中既有「上克下」又有「下克上」（或知一相等无法直接取）
取法：从各克处出发，沿地盘顺序往前数，统计路途经过多少「被克地支」，经过克最多的那条路的起点上神为初传
深浅规则：孟（寅申巳亥）> 仲（子午卯酉）> 季（辰戌丑未），深者优先
相等时：见机格（孟上神）> 察微格（仲上神），或阳日取干上/阴日取支上
记：走得越远、克得越多，说明你涉险越深，取最深那条路
📐 推导步骤（涉害法是九宗门中最复杂的，耐心看完）
第①步：四课中既有上克下又有下克上（混合克），或比用法后仍有多个同阴同阳候选无法取舍
第②步：列出所有参与克的候选上神（上克下取上神，下克上取下神）
第③步：判断各候选在地盘的「位置类型」（这决定了"涉害深度"）：
　　孟位（寅申巳亥）= 涉害最深 — 离老家最远，路途最长，遭遇克制最多
　　仲位（子午卯酉）= 涉害居中
　　季位（辰戌丑未）= 涉害最浅 — 离老家最近，经历最少
第④步：取涉害最深的候选为初传（孟 > 仲 > 季）
第⑤步：若多个候选涉害深度相等（均在孟位，或均在仲位），用复等格：阳日取干上神（第一课），阴日取辰上神（第三课）
　　注：见机格=取孟位者发用；察微格=取仲位者发用——均已在第④步"孟>仲>季"的深度比较中体现
💡 为何孟位最深？把每个候选想象成从"老家"（本宫）出发旅行的人——寅申巳亥（孟）路途最长，沿途遇到被五行克制的地方最多，所以"涉害"最深，动能最大，最有资格发用。
举例①：混克候选有「寅（孟，第一课）」和「辰（季，第三课）」→ 孟 > 季 → 初传 = 寅
举例②（平局）：候选「寅（孟，第一课·日干上）」和「申（孟，第三课·日支上）」→ 同是孟、深度相等 → 复等格 → 阳日取干上神 = 寅 → 初传 = 寅
遥克课
无克 · 日干与上神隔空克
›
判断：四课上下神之间无直接克，但日干与第2/3/4课上神之间存在克
蒿矢（上神克日干）：「上神主动打日干」→ 取那个上神为初传，优先
弹射（日干克上神）：「日干打出去」→ 取被克的上神为初传
多处遥克：按知一/涉害的比用法处理
记：没打到面前，隔空喊话——蒿矢是被人打，弹射是自己射出去
📐 推导步骤
第①步：先确认四课上下之间无任何正克（每课上下五行相生、比和或无关系）
第②步：取出日干的五行属性（甲乙=木 · 丙丁=火 · 戊己=土 · 庚辛=金 · 壬癸=水）
第③步：逐一对照第二、三、四课的上神（天盘地支）五行：
　　□ 若上神五行 → 克 → 日干五行 → 标记为「蒿矢候选」（外力来打我）
　　□ 若日干五行 → 克 → 上神五行 → 标记为「弹射候选」（我主动出击）
　　□ 注意：第一课上神不参与，它是日干的直接上神，属正克范围
第④步：优先取蒿矢（被打更紧迫）；若无蒿矢，则取弹射。取对应上神为初传
第⑤步：若多处同类遥克，再按比用法（阴阳相比）筛一次
💡 蒿矢举例：甲日（木），四课无正克。检查2/3/4课上神：第三课上神 = 申（金），金克木 = 申克甲日干 → 蒿矢格，初传 = 申
弹射举例：甲日（木），无蒿矢候选。第二课上神 = 未（土），木克土 = 甲克未 → 弹射格，初传 = 未
联想记忆：蒿矢 = 用芦苇秆射我（力量弱，伤害轻，但主动攻我）；弹射 = 我用泥弹打出去（主动出击，力也不强）
昴星课
无克无遥克 · 四课完整
›
判断：四课（完整）既无直接克，也无遥克
取法：取地盘酉位上的天盘地支为初传（酉=从魁，昴星宿所在）
刚日（阳干）：从酉上取，祸从外起；柔日（阴干）：从酉上取，祸从内起
象意：四课死气沉沉，让西方肃杀之神出面决断
记：实在没得选，就让酉位（从魁）出来担大旗
📐 推导步骤
第①步：逐一核查——四课无正克（上下不克）→ 遥克也没有（日干与各课上神不克）→ 方才启用昴星法
第②步：在地盘上定位「酉」的固定位置（地盘各支永远不动，酉就是正西方那格）
第③步：看天盘中，位于「地盘酉位」正上方的地支 → 即为初传
第④步：中末传照常从天地盘顺推
💡 为何取酉？昴星宿（二十八宿）居于西方酉位，象征肃杀决断之气。四课死寂无克，系统被迫借西方金气强行启动三传。
举例：当前天地盘中，地盘酉位正上方的天盘地支是「午」→ 昴星课，初传 = 午
别责课
无克无遥克 · 三课（四课有重复）
›
判断：四课中有重复（实际只有三课），且无克无遥克
阳日取法：找日干的天干六合地支（甲合己→找己所在支/乙合庚→找庚所在支…），取该地支天盘为初传
阴日取法：找日支三合局的中间一支（如日支巳→巳酉丑三合，取酉），取其地盘地支为初传；中末传取干上神
六合：甲己·乙庚·丙辛·丁壬·戊癸；三合：寅午戌·申子辰·巳酉丑·亥卯未
记：四课残缺，靠「合」字来牵线找初传
📐 推导步骤
第①步：确认四课有重复（如第一课=第三课），实际只有三课，且无克、无遥克
第②步（阳日）：
　　① 找日干的「天干六合」对应天干（甲→己·乙→庚·丙→辛·丁→壬·戊→癸）
　　② 找该天干的「寄宫地支」（甲→寅·乙→辰·丙→巳·丁→未·戊→巳·己→未·庚→申·辛→戌·壬→亥·癸→丑）
　　③ 看地盘该寄宫位置上的天盘地支 → 初传
第③步（阴日）：
　　① 找日支所在「三合局」（寅午戌·申子辰·巳酉丑·亥卯未）
　　② 取三合局中居中的那支（寅午戌→午；申子辰→子；巳酉丑→酉；亥卯未→卯）
　　③ 看地盘该地支位置上的天盘地支 → 初传
第④步：中传和末传均取日上神（固定，不再推演）
💡 阳日举例：丙日（阳），丙合辛，辛寄宫戌 → 查地盘戌位天盘 = X → 初传 = X，中末传 = 丙上神
阴日举例：丁日（阴），日支亥 → 亥卯未三合，居中是卯 → 查地盘卯位天盘 = X → 初传 = X，中末传 = 丁上神
八专课
特殊 · 干支同宫，两课
›
判断：日干寄宫与日支同一地支（如甲寅日、壬子日、庚申日等），四课中第一二课相同、第三四课相同，实为两课
有克：仍按贼克法（元首/重审/涉害）取初传
无克：阳日从日上神顺数3位取初传；阴日从支上神逆数3位取初传
中末传：均取日上神（不管有没有克）
象意：干支混杂同位，阴阳不分，主私秘淫乱、事情不清
记：两课局面，没克就顺（阳）逆（阴）数三个找初传
📐 推导步骤
第①步：确认日干寄宫地支 = 日支（如甲寄寅·乙寄辰·庚寄申·辛寄戌·壬寄亥·癸寄丑等），四课因此只剩两课有效
第②步：检查这两课是否有克（上克下或下克上）
　　有克 → 按贼克法（元首/重审）正常取初传；中末传均取日上神（固定）
第③步（无克·阳日）：从日上神地支出发，顺时针数3位（子→丑→寅→卯方向）→ 到达的地支为初传
第④步（无克·阴日）：从支上神地支出发，逆时针数3位（卯→寅→丑→子方向）→ 到达的地支为初传
第⑤步：中传 = 日上神，末传 = 日上神（中末均同，固定为日上神）
💡 举例（无克·阳日）：甲寅日（阳），日上神 = 午
顺时针数3位：午→未(1)→申(2)→酉(3) → 初传 = 酉
中传 = 午（日上神），末传 = 午（日上神）
伏吟课
特殊 · 天地盘完全重合
›
判断：月将 = 占时支，天地盘各支都在本位（子还在子，丑还在丑…）
有克：按贼克法取初传；中传=初传所刑，末传=中传所刑
无克：阳日取日上神，阴日取支上神为初传；中末依刑推
刑序：寅刑巳→巳刑申→申刑寅；丑刑戌→戌刑未→未刑丑；子刑卯→卯刑子；辰午酉亥自刑（遇自刑则取日辰并用）
象意：万物潜伏不动，主隐匿、事不明、静中难动
记：天地合体不动，只能靠「刑」来撬动三传
📐 推导步骤
第①步：确认月将 = 占时地支（如月将午、占时也是午时）→ 天地盘完全重合，各支都回到本位
第②步：检查四课是否有克
　　有克 → 按贼克法（元首/重审）取初传；但中末传须改用刑法（见第④步）
第③步（无克时）：阳日取干上神（第一课上神）为初传；阴日取支上神（第三课上神）为初传
第④步：用刑序推中末传（初传刑→中传；中传刑→末传）：
　　寅→巳→申→寅（三角循环）
　　丑→戌→未→丑（三角循环）
　　子→卯→子（对刑循环）
　　辰·午·酉·亥 = 自刑（自己刑自己，此时取日干上神与支上神并用为杜传）
💡 举例（无克·阳日）：庚申日，月将申·占时申时 → 伏吟！
庚寄宫申，干上神 = 申（天地盘重合时，申位上的天盘也是申）
初传 = 申 → 申刑寅 → 中传 = 寅 → 寅刑巳 → 末传 = 巳
为何用刑？天地盘冻结，一切静止，只有「刑」这种强制撕裂的力量才能打破静止，撬动三传流转。
返吟课
特殊 · 天地盘各居对冲
›
判断：天地盘各支居于对冲位（子在午位、午在子位……十二支全部如此）
有克：按贼克/涉害法取初传；中传=初传冲位，末传=中传冲位（即回到初传）
无克（井栏射，丁己辛+丑未日）：取支上神所刑地支为初传；中传=初传冲，末传=中传刑
象意：来去相冲，反复无常，主事情不定、往返变化
记：天地对冲，三传也跟着「冲来冲去」反复
📐 推导步骤
第①步：确认月将与占时相冲（如月将子·占时午时，子午相冲）→ 天盘与地盘各支全部对调到冲位
第②步：检查四课是否有克
　　有克 → 按贼克/涉害法正常取初传（方法同前）
第③步（有克时）中末传固定公式：
　　中传 = 初传的冲位地支（子冲午·丑冲未·寅冲申·卯冲酉·辰冲戌·巳冲亥）
　　末传 = 中传的冲位 → 又回到初传对面，来回反复
第④步（无克时·井栏射）：仅限丁己辛日+丑未时出现
　　取支上神所刑之地支为初传；中传 = 初传冲；末传 = 中传刑
💡 举例（有克）：壬日，返吟课，克取法得初传 = 午
中传 = 午冲 = 子 → 末传 = 子冲 = 午（又回来了！）
三传：午→子→午，来回横跳 → 这正是"返吟"反复无常的象意
记忆口诀：返吟三传冲来冲去，事情就像乒乓球，一来一回定不了

第二部分：四课与三传的底层逻辑深度解析

剥开玄学外衣，大六壬是一套严密的数据建模与状态机系统。

一、四课的底层逻辑：建立"主客"对象模型

四课的本质是从庞杂的天地盘数据库中，实例化出参与事件的核心对象，并读取它们的静态初始数据（State）。

  1. 十干寄宫（类型转换）：天干代表求测者，但无法直接代入地支矩阵。寄宫等同于将天干"类型转换"并分配到地支矩阵的合法内存地址中。
  2. 四象架构：
    • 第一课（日课）：主体表象（我方现状）
    • 第二课（日阴课）：主体潜意识/后台（我方底牌、隐情）
    • 第三课（辰课）：客体表象（对方/事件的现状）
    • 第四课（辰阴课）：客体潜意识/后台（对方/事件的底牌、暗流）
二、三传的底层逻辑：触发"异常"与状态流转

三传是动态的执行流水线（Execution Pipeline），代表事物从起因到结果的演化。

  1. "克"为触发器：系统的和谐态是静止的。只有出现"克"（五行失衡），才相当于程序抛出了"异常（Exception）"。九宗门算法就是一套优先级明确的 if…else 分支，用于捕获引发系统失衡的"第一矛盾点"。
  2. 状态演化链条：
    • 初传（发端）：捕获的异常本身（Input），决定事件因何而起。
    • 中传（过渡）：初传落地后的环境牵扯（Process），运行时状态。
    • 末传（归宿）：事件链条走完后的最终输出（Return Value）。
核心总结：
大六壬通过时间与空间的叠加（天地盘），实例化出主客双方的明暗状态（四课），进而捕获系统内部的五行矛盾（克）作为触发器，最终推演出事件完整生命周期（三传）的数据模型。

六壬运作原理·白话入门
你告诉它「哪天、几点」起的念头，它先摆出一张盘，再从盘里找出「导火索」，顺着导火索推出「起因→经过→结果」，最后给每个字贴上含义，读出吉凶成败。就这么一条流水线。
这台机器的四层结构
第4层 · 翻译层　给每个字贴"性格标签"和"便利贴"，读出人事吉凶
第3层 · 剧情层　起因 → 经过 → 结果（事情怎么发展）
第2层 · 站位层　我方、对方各自现在是什么状态
第1层 · 摆盘层　固定的格子 + 转一圈盖上去的一层
⚠ 摆盘和站位是死规矩——同一天同一时刻，谁来摆都一样，没有半点随意。真正"玄"、靠经验的，只有最上面读吉凶那层。
① 地盘（固定不动）：十二个字（子丑寅…亥）均匀排成一圈，永远不动。像十二个固定车位，只提供"地址"。

② 天盘（转一圈盖上去）：同样这十二个字再拿一份，整体转一个角度盖在地盘上。转多少度，就是这张盘独一无二的"时间指纹"。

③ 月将加时（唯一要算的一步）：把"月将"这个字对准"你起念的那个时辰"，其余的字顺着排好。——错一格，整张盘全错。

四课（四对站位）：给"我"和"对方"各自看一眼"头顶上盖着什么字"，各看两层，凑成四对。

· 我方（日干借住的格子）：头顶第一个字 → 这个字再往上一层得第二个字
· 对方（日支的格子）：头顶第一个字 → 这个字再往上一层得第二个字

这四对，就是此刻这件事的关系快照——我现在被什么笼罩、对方/事情现在是什么状态。但这只是静止的照片，还没告诉你事情会怎么发展。
一张安安静静、谁也不惹谁的盘，不会"出事"。事情之所以发生，是因为"失衡"。而最小的失衡，就是两个字之间相克——你就理解成两个字在掐架。谁在掐架，谁就是这件事的导火索。
找到导火索后，顺着盘往下推两步，得到三段式剧情（三传：初、中、末）：

初传：事情的根源、最先动起来的那个点（导火索）
中传：中间的过程、会碰到的人和事
末传：最后的结果、归宿

怎么推：导火索这个字 → 看它头顶盖着哪个字 → 那个就是中传；中传同样再往上看一步 → 得到末传。像踩着石头过河，连跳两步就到。
第一步：先看盘里有没有人在掐架
· 没人掐架 → 跳到"没人掐架怎么办"
· 有人在掐 → 往下走

第二步：优先抓"下面欺负上面"的那一对
· 下面的欺负上面的（臣顶撞领导）——反常，往往才是真正的乱源，优先抓它
· 上面的压下面的（领导管下属，正常）——只有在没有下犯上时才轮到它
第三步：三道筛子（哪道能缩到只剩1个，就在那停下）
第①道：只有一对在掐？→ 它就是导火索 ✓
好几对都在掐 ↓

六壬算法逻辑梳理·进阶
大六壬整体逻辑算法梳理

以程序算法视角完整拆解大六壬推演引擎：五个基础阶段构建从起盘到断局的完整流水线，五个高阶模块深入异常处理、类神并发、个性化密钥、神煞扩展与三式联动。

在大六壬的底层数据结构与基础运行流水线搭建完毕后，进阶学习可以像推进项目开发一样，按以下顺序逐步完善算法的边缘测试、变量权重与最终输出模块：

  • 第一阶段 · 边界测试（Edge Cases）——当四课中出现多克、零克、数据缺失或盘面死锁时，系统如何依次调用比用、涉害、遥克、昴星、别责/八专、伏吟/返吟等算法分支，保证永远输出唯一三传。
  • 第二阶段 · 权重系统——引入月建与日辰作为全局环境变量，叠加十二长生状态机，计算盘面每个地支的能量级别；同时处理空亡与刑冲克害带来的干扰与损耗。
  • 第三阶段 · 类象数据库（Object Mapping）——把抽象的干支符号翻译成具体人类社会事件：地支是物理实体（名词），天将是属性标签（形容词），两者拼接输出具体象意。
  • 第四阶段 · 设计模式（课格）——古人从海量盘面总结出高频结构，认出课格即可跳过逐点分析，直接调用缓存结论。
  • 第五阶段 · 断局输出（Output Generation）——确定视觉焦点（先锋门），结算初传与日干的交互关系，最后推算应期时间戳。
基础五阶段

当"贼克法"（四课中仅有一克）失效时，系统按严格优先级依次调用后续分支。以下是完整的六大异常处理机制：

一、比用法（极性过滤算法）

触发条件：四课中出现两重、三重或四重克，无法直接判定初传。

底层逻辑：与日干阴阳属性相同的克，对我产生的影响最直接。

日干阴阳取哪个克为初传典型例子
阳日（甲丙戊庚壬）阳地支（子寅辰午申戌）甲日多克，取属阳者
阴日（乙丁己辛癸）阴地支（丑卯巳未酉亥）丁日多克，取属阴者

中传与末传：初传确定后，中末传恢复默认（查天地盘落位顺延）。

二、涉害法（路径遍历与深度计算）

触发条件：比用法过滤后仍有两个以上阴阳属性相同的地支。

底层逻辑："涉害"意为跋山涉水经历克害——经历磨难越多，动能越大。各候选地支从其地盘老家（本位）出发，顺时针走到天盘当前位置，统计沿途被克次数，受克最深者取为初传。

地支位置涉害深度备注
孟位（寅申巳亥）最深（三至四重克）动能最大，优先取
仲位（子午卯酉）中等（两重克）次选
季位（辰戌丑未）最浅（一重克）末选

二次防死锁机制（见机与察微）：若两候选克数完全相同：

  • 见机：落在第一/二课（日干之上）者为初传
  • 察微：落在第三/四课（日支之上）者为初传
  • 缀瑕格：若两者同时临干或同时临支，阳日从地盘"寅"顺时针寻找，阴日从地盘"申"逆时针寻找，先遇者为初传
三、遥克法（全局越权扫描）

触发条件：四课上下完全无克（相生或比和），贼克、比用、涉害全部失效。

底层逻辑：内部无矛盾，向外部找干涉——跳出四课的上下对应，跨层级查询。

  • 扫描对象：第二、三、四课的天盘地支
  • 神机（蒿矢）：这三个天盘地支中有克日干者，取为初传（外力来搞我）
  • 鬼觉（弹射）：若无克日干者，则看日干克哪个天盘地支，取受克者为初传（我主动出击）
  • 多重遥克：再次调用比用法（极性过滤）
四、昴星法（绝对零度下的强制触发）

触发条件：四课无克，且无任何遥克，系统陷入绝对零度的死寂。

底层逻辑：借用宇宙固定物理属性——"酉"是日落之地、阴阳交界之门（昴星在此），强行提取状态。

日干阴阳操作取值
阳日（仰视向外求）去地盘找"酉"位地盘酉上顶着的天盘地支为初传
阴日（俯视向内求）去天盘找"酉"位天盘酉落在的地盘地支为初传
五、别责法 与 八专法（数据缺失处理）

触发条件：第一课与第三课重合，四课缩减为三课甚至两课。

别责法（三课且无克）：

  • 阳日：找日干的"五合"天干的寄宫，取其上神为初传（甲与己合，取己寄宫未的上神）

一、贪生忘克（动态路由重定向）

五行的底层天性是"贪生忘克"——只要有可以投资（生）的目标，就立刻放弃原有的攻击（克）计划。

二、合解冲刑（进程锁死与中断）

当盘面出现"冲"（决裂碰撞）或"刑"（内部折磨），系统会调用"合"机制强行中断冲突。

案例：盘面出现"子午相冲"（合作破裂），但日支或年命出现"丑"。因为"子丑六合"，丑把子锁死，子失去冲撞午的动能。这叫"贪合忘冲"——第三方用极厚利益绑定一方，危机被强行按下暂停键。
